# Safety and disclosure

Do not submit real AI-agent logs, prompts, credentials, tokens, customer records, source code, private file paths, or other sensitive material.

If a fixture or repository file accidentally contains sensitive information, report the exact file and commit privately through GitHub's security-advisory workflow. Do not repeat the sensitive value in a public issue.

For a product security problem affecting [Traceplain](https://traceplain.zakgov.com/), use the contact path published on the product site rather than attaching a real trace to GitHub.
